The Tech Stack: Python (FastAPI/Pytest) for the execution backend, Node.js/TypeScript for the civic runtime.
The Prime Directive: AI proposes, the human disposes. The system is a constitutional state machine. No action is executed without cryptographic human authorization via receipt.json.
Data Sovereignty: The ledger (three_tier_ledger.py) is strictly append-only. History cannot be overwritten.
External Boundaries: Never use external third-party execution APIs. The system relies on local, offline execution (llama-cpp-local-runtime.ts) to maintain absolute sovereignty.
